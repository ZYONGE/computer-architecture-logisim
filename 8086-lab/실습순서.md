# 8086 실습 — 캡처 순서 (개인과제-3)

모든 캡처(표지·소감 제외)는 **바탕 화면에 이름·학번이 보이는 상태**로 찍는다.
(예: 메모/스티커 앱에 `학번 이름`을 써서 DOSBox 창 옆에 띄우고 Cmd+Shift+3 전체 화면 캡처)

## 0. DOSBox 실행 (작업 폴더가 자동으로 C:로 마운트됨)

터미널에서:

    /Applications/DOSBox\ Staging.app/Contents/MacOS/dosbox -conf /Users/jiyongkim/SourceCode/8086-lab/dosbox-8086.conf

## 2. DOSBox 설치 화면

이미 설치돼 있으므로 캡처용으로 지웠다가 다시 설치하면서 터미널 화면을 캡처한다.

    brew uninstall --cask dosbox-staging-app
    brew install --cask dosbox-staging-app

## 3. reg.lst  /  4. reg.exe

DOSBox 안에서:

    masm reg,,reg;
    link reg;
    debug reg.exe
    -r
    -t        (6번 반복: mov → dec → jnz → dec → jnz → nop)
    -q

- `.lst`는 CP949라 DOSBox `type`으로 보면 한글이 깨진다. 보고서에 넣을 텍스트는 Mac 터미널에서 변환:

      cd /Users/jiyongkim/SourceCode/8086-lab && python3 report/lst2utf8.py REG

  → `report/reg.lst.txt` 를 열어 복사 (MASM이 줄바꿈하며 쪼갠 한글도 복구해 줌)
- PPT 15쪽 명령이 위와 다르면 PPT 기준으로 한다 (PPT 미확인).

## 5. stack.lst

    masm stack,,stack;
    link stack;
    stack

변환: `python3 report/lst2utf8.py STACK` → `report/stack.lst.txt`
(원하면 `debug stack.exe` → `t 6` → `d ss:5c 63` 으로 스택 메모리 `78 56 34 12` 도 확인 가능)

## 6. compare.exe  (a<b 와 a>=b 둘 다 찍어 두면 안전)

    masm compare,,compare;
    link compare;
    compare        ← a=1, b=2 입력  →  a < b / X = 5, Y = 7
    compare        ← a=2, b=1 입력  →  a >= b / X = 1, Y = 0

## 7. sample.exe

    masm sample,,sample;
    link sample;
    sample

영문 이름을 입력하고 `!` 로 종료. **Enter 금지**(CR만 출력돼 줄 앞으로 돌아가 덮어씀), 입력기는 영문으로.
